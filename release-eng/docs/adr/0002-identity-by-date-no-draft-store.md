# 版本身份跟发版日期；预览不落盘；编排不续跑

在 ADR 0001「硬闸保留、靠编排辅助」之上修正落地细节：目录包默认身份改为 `release-V` + 发版日期（不再用发版分支归一化作路径）；半自动编排首问后直达 WritePlan 预览，不落闸状态、不考虑编排续跑；评审只走会话预览，不建 `_drafts/` 等仓库落点。`notes/` 兼容读仍按原计划在 0.4 删除并附迁移。

**Status**: accepted

**Supersedes (partial)**: ADR 0001 中「一等公民评审草稿物理通道」「可恢复闸状态」两条后果 —— 改为会话预览 + 无状态文件。

**Considered Options**:
- 保留「身份 = 分支归一化、日期不进路径」→ 拒绝（与 sms-ai 实盘 `release-V{日期}` 及本轮明确偏好不符）
- `_drafts/` 或 gist 作为评审落点 → 拒绝（明确「草稿无需落点」）
- `docs/releases/_work/` 或 gitignore 状态文件支撑续跑 → 拒绝（明确不考虑续跑）

**Consequences**:
- `modes/conventions.md` ①② 须改写：发版日期进入版本身份；改日期可能意味着改路径（规则待钉死）
- 编排器是同会话一次性管道；`resume` 模式是否保留为人工同身份刷新，与「编排不续跑」分开定
- push-gate 失败时只能停在聊天预览，无目录包、无草稿夹
- 仓内脚本版本对账（原 Q9）本轮未与「草稿落点」一并否决，须单独确认
