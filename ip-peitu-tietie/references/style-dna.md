# 风格 DNA

## 一句话

像从一本旧手帐里撕下来的涂鸦页：整页旧纸、黑墨线、少量复古色语义贴纸，有怀旧和温度，绝不花哨。

## 必须

- 16:9 横版正文配图。
- 整页旧纸：浅米色纤维底铺满画布。纸纹要轻，短中文必须可读。不要纯白，不要浓 kraft 脏纸。
- 黑色墨线为主：细到中等、轻微抖动、可有少量排线/点刻，不机械、不矢量、不厚重描边。
- 大量纸面留白：主体占画面约 40%–60%，至少 35% 安静纸面。
- 少量中文手写批注：最多 5–8 处，每处尽量 2–8 个字。
- 语义贴纸/胶带每张最多 2–3 处，必须承担结构语义（封口=完成、撕开=断点、贴歪=接错）。
- 一张图只讲一个核心动作、结构、状态或隐喻。
- 结构要自然表达，不要在图上写结构类型名称。

## 颜色

- 黑色：墨线、结构、主要手写字、帖帖的五官和手脚。
- 陶土红 / terracotta：帖帖身体色块；以及少数强调标注（问题、断点、结果）。不要让大段字和帖帖身体抢同一块红。
- 灰尘蓝 / dusty blue：只给胶带、少量辅池物件。**不写字。**
- 米色 / cream：纸底，不是第二套角色色。

不要红橙蓝三色说明书分工。蓝色不是标注色。

## 材质借什么、不借什么

校准 `references/style-refs/` 时只借：

- 旧纸底和轻微印刷颗粒
- 黑墨线 + 排线
- 撕边色块、和纸胶带的复古色
- 克制的贴纸厚度感

不要借：

- 参考图 1 的 wink chibi 机器人、星星闪点、磁带布景
- 参考图 2 的齿轮流程图当默认构图
- 多根装饰胶带铺角

## 绝对不要

- 不要纯白产品草图（那是糖糖技能）。
- 不要红橙蓝批注系统。
- 不要商业插画、PPT 信息图、正式流程图、课程课件。
- 不要可爱卡通海报、儿童插画、闪点铺满。
- 不要复杂架构图、精致扁平插画、科技感 UI、真实 App 截图。
- 不要左上角写「Workflow / 系统架构图 / 常见坑 / 路线图」等类型标题。
- 不要把每个节点都解释清楚。

## 审美方向

要有手帐温度、创意、怪、一眼能读。

不要花哨、不要说明书、不要纯白冷感、不要卖萌铺满。
