# 帖帖 IP

## 角色定义

帖帖是 ip-peitu-tietie 的固定视觉 IP：一张会干活的活贴纸。

默认每张图都要出现帖帖。帖帖不是角落装饰、不是吉祥物、不是参考图里的机器人，而是正在变成结构本身的荒诞手帐材料。

## 外形锁定

对照 `assets/character-sheet/00-character-sheet.png`。

- **身体**：近圆的陶土红 / terracotta 贴纸色块，边缘锯齿或花边撕口，有贴纸厚度；侧面是薄片。不是纯黑实心，不是黑豆，不是饼干写实，不是齿轮机器人。
- **脸**：圆脸画在色块正面。
- **五官**：两点墨眼，简单墨线五官；可有一点手帐涂鸦可爱，但不 wink、不 Q 版大眼。
- **手脚**：细墨线肢，偶尔有简单手/脚。
- **情绪星**：每张最多 1 颗手绘小星，贴在帖帖身上或脸侧，只表情绪。不算语义贴纸配额。禁止贴纸星、禁止背景闪点散落。
- **体色**：身体锁陶土红。灰尘蓝只给胶带和辅池物件，不给帖帖皮肤。

## 性格

- 很认真，但做的事有点荒诞。
- 像手帐页上真的负责把结构贴住的那块材料。
- 有一点涂鸦可爱（圆脸），但不卖萌、不眨眼卖乖。
- 有点笨拙，但不蠢。

## 变形规则

变形 = 把陶土红色块撕、贴、卷成结构的一部分：

- 撕成漏斗、贴成门、卷成管子。
- 卡住撕口、封住蜡封、夹进长尾夹、堵住漏掉的口。

变形后仍必须同时认出三件套：**锯齿撕边 + 圆脸两点墨眼 + 陶土红色块**。

如果去掉帖帖，图的核心隐喻还能完全成立，说明帖帖太装饰了；要重写提示词，让帖帖成为动作主体。

## 常见职责

让帖帖承担核心动作：

- 把自己撕成漏斗去分拣。
- 贴在门上当门，或从门缝揭开。
- 卷成管子让东西通过或卡住。
- 封蜡、揭蜡、夹住、钉住、接错双面胶。
- 卡在撕口里，两边接不上。
- 钻进抽屉/牛皮袋里找沉淀下来的东西。
- 站在秤上或变成秤盘的一部分去称。
- 需要讲系统时，可把自己贴在一个齿轮或圆筒上操作，但仍是活贴纸，不是机器人。

## 禁止

- 不要画成小黑（黑豆 + 白点眼 + 细腿 + 纯黑身体）。
- 不要画成糖糖（婴儿）。
- 不要画成参考图里的 chibi 机器人、屏幕脸、wink。
- 不要复杂服装、表情包、闪亮大眼。
- 不要让帖帖只是贴在角落里看。
- 不要让帖帖抢走结构表达（满页都是角色特写）。
- 不要每张换皮肤颜色。
