# QA Checklist

## 必过项

- 是 16:9 横版。
- 背景是整页浅米旧纸，纸纹轻、字可读。
- 有帖帖。
- 帖帖是活贴纸：撕边 + 圆脸两点墨眼 + 陶土红色块身体（不是纯黑，不是小黑，不是糖糖，不是机器人）。
- 帖帖承担核心动作，变成结构的一部分，不只是装饰。
- 没有复刻 style-refs 或旧小黑构图，而是为当前文章生成了新隐喻。
- 画面有手帐温度和创意，但不花哨。
- 主体不超过画面约 60%。
- 一张图只讲一个核心结构。
- 中文标注少、短、能读；黑墨为主，强调才用陶土红。
- 灰尘蓝不写字，只给胶带或辅池物件。
- 语义贴纸/胶带最多 2–3 处，且在干活。
- 情绪星最多 1 颗，贴在帖帖身上或脸侧。

## 失败信号

出现以下情况，重生成或局部编辑：

- 左上角有「常见坑 / Workflow / 系统架构图 / 路线图」等标题。
- 帖帖像吉祥物、表情包、chibi 机器人、wink 屏幕脸。
- 帖帖是黑豆 + 白点眼，或婴儿。
- 画面像 PPT、课程课件、正式流程图。
- 元素太多、箭头太多、节点太多、贴纸铺满。
- 星星闪点散落、小花、装饰磁带。
- 文字变成大段解释。
- 背景是纯白产品草图；或纸纹浓到吃字。
- 真实 UI 截图或科技感界面。
- 中文错字严重或标注不可读。
- 画面太死板，没有手帐隐喻。
- 和 `references/style-refs/` 里的书桌机器人或齿轮数据库构图过于相似。

## 迭代方法

- 太普通：让帖帖撕/贴/卷成结构本身，换一个主池物件。
- 太复杂：删节点，只保留一个动作和 3–5 个短标注。
- 太花哨：删闪点、删装饰胶带，只留 2–3 处语义贴纸。
- 太可爱 / wink：压回圆脸 + 两点墨眼，情绪星最多一颗。
- 太 PPT：去掉标题、整齐网格和过多箭头，改成手帐页上的一个场景。
- 塌成小黑：身体改回陶土红撕边色块，去掉白点眼和纯黑填充。
- 纸纹太重：减轻颗粒，保住短中文对比。
- 文字错：优先局部编辑；错得多就重生成并减少标注数量。

## 交付判断

高质量图应该让读者先觉得「像一页旧手帐」，然后 1 秒内看懂结构。

如果第一眼像教程页、纯白产品草图、或装饰铺满的可爱手帐，就不合格。
