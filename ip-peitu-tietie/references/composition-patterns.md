# 构图模式与原创规则

## 基础结构类型

选择一种结构即可，不要混太多。

### Workflow 流程

适合：输入 -> 处理 -> 输出，判断链路，从进到出。

画法：左侧输入，中间帖帖变成处理装置（漏斗/管子/门），右侧输出。主流向用黑墨箭头，断点用陶土红短字。

### 系统局部

适合：过滤、存储、放行、队列。仅当正文在讲软件/agent 时，才从辅池取 1 个物件。

画法：只画 3–5 个核心模块，帖帖参与其中一个关键动作（贴住、堵住、揭开）。

### 前后对比

适合：混乱/有序，散开/收拢，卡住/跑起来。

画法：左乱右稳，中间一条黑墨流向。帖帖可以在左边是揭开的撕口，右边是封住的蜡封。

### 角色状态

适合：痛点、信息过载、从卡住到贴住。

画法：2–4 个小状态，每个状态一个短标注；每格都是同一张帖帖。

### 概念隐喻

适合：一个大的手帐物件讲清一个判断（袋子=沉淀，秤=判断，门=放行）。

画法：一个主物件，少量输入，一个输出。要有记忆点。帖帖必须是物件的一部分。

### 方法分层

适合：方法论、层级、能力栈。

画法：一层层纸盒或风琴夹，不要正式金字塔；帖帖在某一层被夹住或往上贴。

### 地图路线

适合：从想法到完成、用户路径、学习路线。

画法：一条弯曲路径，少量节点；帖帖沿路贴节点或把路径撕开。

### 小漫画分镜

适合：失败到成功、过程、吐槽。

画法：2–4 个小场景，每格只表达一个动作，格子可以是手帐页上的胶带框。

## 原创隐喻生成法

每次都从当前文章重新发明隐喻，不能照搬旧图。

### 三步

1. 把抽象概念换成一个物理动作：卡住、漏掉、变重、分拣、沉淀、开门、折叠、拆包、回流、钉死。
2. 从主池选 1–2 个手帐物件承接这个动作。
3. 让帖帖承担动作：不是站旁边，而是被撕、被贴、被卷成那个物件的一部分。

### 主池（默认）

按认知动作取，每张只选 1–2 个：

- 卡住 / 断点：撕口、未撕开的页、缺环的活页、揭不开的蜡封
- 分流 / 归类：风琴夹、抽屉隔板、活页环
- 收集 / 沉淀：牛皮袋、档案柜、纸箱、抽屉、信封
- 判断 / 度量：秤、尺子
- 接上 / 接错：回形针、长尾夹、橡皮筋、双面胶
- 放行 / 拦住：门、钥匙、锁、蜡封
- 送出 / 留下凭证：邮筒、票根、复写纸、书签
- 压缩 / 变形：纸团、漏斗、管子
- 临时 / 会掉：便签
- 切断 / 钉死：剪刀、图钉
- 溢出：墨水瓶

### 辅池（仅正文在讲软件/agent）

齿轮、磁带、圆筒、插头、拨动开关。每张最多 1–2 个，必须手帐化，禁止架构标题和密节点。

### 帖帖动作池

- 撕、贴、卷、封、揭、夹、盖、堵、接、称、分、钉
- 动作要服务核心意思，不要为了怪而怪

## 反复刻规则

不要默认打开或复刻 `assets/examples/`、`references/style-refs/`、`archive/`。`assets/examples/` 只校准线条密度、留白和帖帖参与方式。风格参考只校准纸、墨、胶带材质。旧小黑演示图在 `archive/ian-xiaohei-examples/`，只作「不要复刻」对照。

除非用户明确说「照这张 / 复刻这个构图」，否则不要复用：

- 参考图 1：书桌前 wink 机器人 + 磁带 + 星星闪点
- 参考图 2：齿轮组 + 数据库圆筒流程
- 旧小黑构图：传送带断点、拉判断杆、切素材鱼、盖章话术、承接路径、漏斗分拣流量

同类主题也要换新隐喻。例如「断点」不一定画齿轮卡住，可以画帖帖卡在撕开的页缝里；「过滤」不一定画漏斗图标，可以画帖帖把自己撕成漏斗，底下只漏出一枚票根。
