# ip-peitu-tietie 正文配图

并列于糖糖技能的第二套中文正文配图能力。本文件只收术语，不收实现。

## Language

**帖帖**：
本技能的视觉 IP。活贴纸：撕边陶土红色块身体、圆脸、两点墨眼、细墨线手脚。每张最多 1 颗手绘小星当情绪点，不 wink、不铺闪点。变形后仍靠撕边 + 圆脸 + 陶土红认出。
_Avoid_: 小黑, Xiaohei, 糖糖, 吉祥物, chibi 机器人, 实心纯黑身体, 用 02 称呼角色

**活贴纸**：
帖帖的形态类型：身体是撕过边的复古色块；变形 = 撕成漏斗、贴成门、卷成管子。
_Avoid_: 黑豆+白点眼+细腿, 婴儿操作员, 图标人

**系统生物**：
帖帖的职能：非人，变成结构装置的一部分，不是站在旁边看。
_Avoid_: 小黑换皮, 装饰贴纸

**风格 DNA**：
锁定为**复古手帐**，不与糖糖技能共享纯白细线红橙蓝白板草图。
_Avoid_: 画风, Ian 风格, 与 ip-peitu-tangtang 共用的 style-dna

**复古手帐**：
整页旧纸（米色纤维底铺满画布）+ 黑墨线 + 少量复古色语义贴纸/胶带。有怀旧和温度，绝不花哨。
_Avoid_: 纯白产品草图, 红橙蓝批注系统, 手帐装饰铺满, 浓 kraft 吃字, chibi wink 机器人

**语义贴纸**：
胶带/贴纸必须承担结构语义，每张最多 2–3 处。帖帖身上那颗情绪星不算在这 2–3 处里。
_Avoid_: 星星闪点铺满, 小花, 装饰磁带, 多根和纸胶带布景

**情绪星**：
贴在帖帖身上或脸侧的 1 颗手绘小星，只表情绪，不当背景装饰。
_Avoid_: 贴纸星, 散落闪点, wink

**定妆图**：
`assets/character-sheet/` 中的帖帖三视图基准，生成时以它锁脸、撕边和体色。
_Avoid_: 只靠文字描述锁 IP

**隐喻词汇**：
默认从**主池**长出画面；正文在讲软件/agent 时才动用**辅池**。每张只取 1–2 个物件。
_Avoid_: 素材鱼, 盖章话术, 一鱼多吃, 承接路径, 默认架构图

**主池**：
手帐认知物理词库：撕口、未撕开的页、活页环、蜡封、风琴夹、抽屉隔板、牛皮袋、档案柜、纸箱、抽屉、信封、秤、尺子、回形针、长尾夹、橡皮筋、双面胶、门、钥匙、锁、邮筒、票根、复写纸、书签、纸团、漏斗、管子、便签、剪刀、图钉、墨水瓶。
_Avoid_: 把主池一次画进同一张图

**辅池**：
齿轮、磁带、圆筒、插头、拨动开关。仅当正文在讲系统时用，每张最多 1–2 个。
_Avoid_: 默认画齿轮流程图

**手帐标注**：
短中文手写：黑墨为主；强调用陶土红；灰尘蓝不写字，只给胶带和辅池物件。
_Avoid_: 红橙蓝说明书分工, 大段解释

**正文配图**：
插在中文文章段落之间、锚定一个认知结构的图，默认 16:9 横版。
_Avoid_: 插画（笼统）, 信息图, 课件

**ip-peitu-tietie**：
技能包目录名与调用 token。不是帖帖的名字。
_Avoid_: 小黑技能, Ian 配图, ip-peitu-02, 用 02 称呼角色
