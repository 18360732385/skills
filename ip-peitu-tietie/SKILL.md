# 帖帖复古手帐正文配图

## 核心定位

为中文文章设计和生成 16:9 横版正文配图。目标不是做商业插画、PPT 信息图或可爱卡通，而是把文章里的关键判断、流程、结构、状态或隐喻，变成一张从旧手帐里撕下来的涂鸦解释页：清爽、有温度、可读但不说明书。

默认视觉 IP 是「帖帖」：撕边陶土红色块身体、圆脸、两点墨眼、细墨线手脚。帖帖必须变成画面核心结构的一部分（撕成漏斗、贴成门、卷成管子），不能只是贴在旁边当装饰。

本技能与糖糖手绘配图（`$ip-peitu-tangtang`）并列：共享「正文配图工作流」，不共享白板草图风格，也不共享角色。

## 先读这些参考

按任务需要读取，不要一次塞满上下文：

- `references/style-dna.md`：复古手帐 DNA、颜色、文字、禁忌。
- `references/tie-tie-ip.md`：帖帖的形象、性格、动作库和禁忌。
- `assets/character-sheet/00-character-sheet.png`：定妆图，锁脸、撕边和体色。
- `references/composition-patterns.md`：结构类型、原创隐喻方法和反复刻规则。
- `references/prompt-template.md`：单张生图提示词模板。
- `references/qa-checklist.md`：生成后检查和迭代规则。
- `assets/examples/`：8 张结构演示图，只作低频风格校准（线条密度、留白、帖帖参与方式），不进入默认生成路径，不要照抄构图。
- `references/style-refs/`：只作材质校准（纸、墨、胶带），不进入默认生成路径，不复刻构图或角色。
- `archive/ian-xiaohei-references/`：旧小黑圣经，仅供对照「不要画成什么」，不进默认路径。

## 工作流

### 1. 消化正文

先读用户给的正文、链接、Notion 页面、Markdown 文件或截图内容。提炼：

- 核心观点是什么
- 哪些段落承担认知转折
- 哪些内容适合用图解释
- 哪些地方只适合文字，不需要图

不要平均配图。优先选择「认知锚点」，例如：核心判断、两个断点、输入输出闭环、分流、前后对比、卡住/放行、角色状态变化。

### 2. 先出配图策略

如果用户只是说「分析怎么配图 / 思考哪些地方需要配图」，先给 shot list。每张图写清楚：

- 放在哪个段落后
- 图的主题
- 核心意思
- 结构类型
- 帖帖在图里如何变成结构的一部分
- 建议元素（主池 1–2 个；仅当正文在讲软件/agent 时才加辅池）
- 建议中文标注词

默认 4–8 张。文章很短时 1–3 张；长文也不要轻易超过 9 张。够用就好，避免把正文做成画册。

### 3. 单张生成

如果用户明确要求「生成 / 输出 / 做图 / 帮我生成」，不要停下来等确认；用内置 `image_gen` 每张单独生成。不要把多张图拼在一张里。生成前对照定妆图锁帖帖。

每张图只讲一个核心结构。提示词必须包含：

- 16:9 横版中文正文配图
- 整页旧纸（浅米色纤维底，纸纹轻、对比够读短中文）
- 黑色墨线手绘
- 少量语义贴纸/胶带（每张 2–3 处，必须承担结构语义）
- 黑墨中文手写为主，强调用陶土红；灰尘蓝不写字
- 帖帖作为核心动作主体（活贴纸变形）
- 禁止 PPT、商业插画、chibi wink 机器人、红橙蓝说明书、左上角类型标题

不要复刻过往案例或 `references/style-refs/` 里的构图。每次都要从当前文章重新发明一个奇怪但成立的隐喻。

### 4. 检查与迭代

生成后检查 `references/qa-checklist.md`。如果出现以下问题，优先重生成或局部编辑：

- 帖帖只是装饰，没有变成结构的一部分
- 画面太满、贴纸太多、闪点铺满
- 太像流程图/PPT
- 中文太多或错字严重
- 左上角出现类型标题
- 画成小黑、糖糖、或参考图里的 chibi 机器人
- 背景是纯白、没有旧纸感；或纸纹浓到吃字
- 帖帖身体变成纯黑，或撕边/圆脸/陶土红丢失

### 5. 保存交付

如果用户在 workspace 内工作，把最终图复制到：

```text
assets/<article-slug>-illustrations/
```

按顺序命名：

```text
01-topic-name.png
02-topic-name.png
```

保留原始生成文件，不要覆盖已有资产，除非用户明确要求替换。

## 输出口径

生成前的策略输出要短而准。生成后的交付要包含：

- 生成了几张
- 每张图的用途
- 保存路径
- 哪些图最稳，哪些图是可选

不要长篇解释风格理论；让图自己说话。
