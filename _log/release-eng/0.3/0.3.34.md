# release-eng 0.3.34

日期：2026-11-23（Asia/Shanghai）

## 要点

- **新功能：本版 SQL 统计文档 `sql/README.md`**（目录包内自动生成）：
  - 新增 `scripts/release-sql-stats.mjs`（纯函数 `buildSqlStatsMarkdown`）：输出总览、按提交人两段。
  - 总览：DDL / DML 的**文件数与语句数**及整理文件链接（缺侧显示 `—`）。
  - 按提交人：每个提交人名下的 SQL 文件与执行序（类别内序 + 全局序）。
  - 跳转：SQL 文件名链接到对应整理文件起始行 `./release-V{yyMMdd}-DDL|DML.sql#L<行号>`，并附「DDL/DML 第 N 行」文字兜底。
- `release-format.mjs` 新增 `countSqlStatements(src)`：去注释/字符串后按 `;` 统计语句数（字符串内分号不切断）。
- `release-sql-bundle.mjs`：新增 `gitLastAuthor`（`git log -1 --format=%an -- <path>`）；为每个源文件补 `srcPath`/`author`/`statements`，写整理文件后生成 `sql/README.md`，返回 `statsPath`/`stats`，CLI JSON 同步输出。取不到作者记 `未识别`；失败路径仍保留旧产物。
- `release-note-merge.mjs`：把 `sql/README.md` 登记为 `sql-stats` 附属文件（进「包内附属文件」表），输出 JSON 增加 `sqlStats`；「包内附属文件」说明补统计文档。
- `selfcheck.mjs`：`SCRIPTS` 加入新模块；新增 034 A/B/C 断言（语句计数口径、Markdown 总览/分组/`#L` 锚点、`runSqlBundle` 落盘且锚点行号与整理文件一致）。
- 未改动 `sql/refs/` 与两份整理文件字节（`contentSha256` 不变）。

## 验收

- `node scripts/selfcheck.mjs` → PASS 423/423（含 034 A–C）
- `node scripts/sync-skill-version.mjs --check` → exit 0（monorepo）
- 临时仓库端到端：`runSqlBundle` 生成 `sql/README.md`，`#L` 行号与 `-- >>> begin:` 行一致；无 git 时提交人为「未识别」
