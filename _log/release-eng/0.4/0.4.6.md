# 0.4.6 — 读取端接受 UTF-16

日期：2026-11-27

## 本版

发版单、`releases.md`、freeze / artifacts JSON、repo-profile、SQL 与配置文件的读取接受 UTF-8 与 UTF-16（含 BOM；UTF-16 LE 的 ASCII 文本无 BOM 也可）。

写出仍是 UTF-8。Windows 上大 JSON 继续用 `--out`，避免 PowerShell `>` 把新文件写成 UTF-16。

## 验证

- `node scripts/selfcheck.mjs`
- `node scripts/sync-skill-version.mjs --check`
