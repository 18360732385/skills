# release-eng 0.4.4

日期：2026-11-26

## 变更

- `docs/releases/releases.md` 增加仓级「SQL 扫描」：SQL 目录（相对仓库根）与 SQL 格式（`flyway` 或文件名 glob）。缺一即首次使用，与「首次发版」无关
- 首次使用时首问必答这两项；两项都有效后 `release.mjs sql-profile --apply` 写入索引，不创建发版目录包
- 已记录后 freeze / prepare / note-merge 只收录该目录之下、且文件名符合该格式的 SQL。不传参数且索引未记录时，仍按 `db/migration` + Flyway，避免旧调用被改写
- prepare 在索引未记录且未传 `--sql-dir`/`--sql-format` 时 exit 1
- 自定义 glob 解析不出版本号的文件仍进入 SQL 候选，排序靠后，归类为「未分类」

## 验收

`node scripts/selfcheck.mjs` · `--layer unit` · `--layer contract`
