# 0.4.7 — 定版缺口收口

日期：2026-11-27

## 本版

对照实仓清单修了这些定版行为：

- 生产库连接支持 Spring 占位默认值 `${VAR:jdbc:…}`，能抽出库名和脱敏连接串。
- 定时任务候选只收 cron / fixedDelay 叶子。父级 map、裸 `scheduling`、时区键不再进 `draft.jobs`，也不再报缺 cron。
- 仓内 SyncTaskCode 枚举即使没有 docs 命中也进 `draft.jobs`，说明写「建议人工确认」。
- 同日身份已经归档时，prepare 默认退出并提示改日期；seal 在目标归档目录已存在时拒绝覆盖。
- 经典 `V1__…` 脚本若正文只有 DDL 或只有 DML，不再每次都要 `--sql-ai-json`。归类失败且本轮还没有发版单时，不留下空的身份目录。
- 发版单 SQL 样表「类型」列使用归类结果。模块没有自己的说明时写「（待补）」，不再复制仓根简介。配置注释不越过无注释的中间级去套文件头。draft-md 行尾写说明，confidence 另列。
- 问卷和 WritePlan 与「身份 = `release-V{yyMMdd}`」对齐。
