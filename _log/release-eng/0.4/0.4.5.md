# release-eng 0.4.5

日期：2026-11-26

## 变更

- 合并来源改口径：只统计**对比版本之后新增**的 git merge 记录。对比版本取 archive 最新已上线发版单「定版引用」的 head；本地可解析且为当前 head 祖先时用 `ref..head`，否则回落定版范围并在 warnings 注明。JSON 新增 `mergeScope`
- 发版单「数据库与 SQL」最多展示前 5 条样表（# / 脚本 / 类型 / 动作），超出注明其余详见 `sql/README.md`
- 发版单「定时任务」最多展示前 5 条样表（taskCode / 名称 / cron），超出注明其余详见 `jobs/README.md`
- 「七、包内附属文件」改为逐项清单：SQL 原件 / 整理 DDL·DML / 配置快照 / 定时任务各一行，链接直接指向包内文件
- 修复文件名含方括号（如 `[sms_db_prod]-V…-DDL.sql`）时 md 链接不渲染的问题；附件链接统一新窗口打开
- 发版单 HTML 视觉重做：封面抬头分栏 + 分支 chip、章节编号方框、核对条、表格密度、附属清单行、移动端与打印
- fixtures 样张同步新章节形态并重渲 `release-note-sample.html`
