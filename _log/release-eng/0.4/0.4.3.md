# release-eng 0.4.3

日期：2026-11-25

## 变更

- 新增 `scripts/release-note-html.mjs`：发版单 md → 同目录同名 `.html` 只读渲染（工单样式，自包含单文件：内嵌 CSS/JS、离线可读、可打印；状态章/核对条/可勾选步骤与验收/签字栏；勾选与折叠为会话级不入档）
- `release-note-merge.mjs`：定版落盘后自动生成/重建 `<identity>.html`（`--no-html` 关闭；dry-run 报告将写 html 路径；渲染失败降级 warning，不阻断定版）
- `release-seal.mjs`：`--apply` 归档侧按「已上线」重渲同名 html（结果 JSON 增 `html` 字段）
- `release.mjs`：新增 `note-html` 别名转发；prepare 模式脚本列表带上 `note-html`
- fixtures：`templates/release-note-sample.md`（示例发版单）+ `release-note-sample.html`（生成的样张，视觉模板样例；不参与 bootstrap 种子）
- 约定：conventions 新增「⑩ 发版单 HTML 渲染」（md 为 SSOT，html 为生成物）
- selfcheck：SCRIPTS 增列；新增 0.4.3 回归块（解析/渲染标记、CLI、note-merge 自动渲染与 `--no-html`、别名、集成 source 断言）

## 验收

`node scripts/selfcheck.mjs` · `--layer unit` · `--layer contract`
