# 0.4.8 — 方括号文件名链接转义

日期：2026-11-27

## 本版

发版单与 `sql/README.md` 里带方括号的整理文件名（`[库名]-V{yyMMdd}-DDL|DML.sql`）在 Markdown 预览中会被截断，链接文字只剩到第一个 `]`。现在统一转义：

- 链接文字按 CommonMark 转义 `[` `]` 与反斜杠；链接目标把方括号写成 `%5B` / `%5D`，保留 `#L` 锚点。入口为 `mdFileLink` / `escapeMdLinkLabel` / `encodeMdLinkDest`。
- 包内附属清单、`jobs/README.md` 真相链接、`sql/README.md` 统计表统一走 `mdFileLink`。
- 发版单 HTML 还原转义后的链接文字，并按编码后的 href 输出；旧的未转义 `[[库名]-V…](…)` 仍可渲染。

## 验证

- `node scripts/selfcheck.mjs`
- `node scripts/sync-skill-version.mjs --check`
