# 0.2.29 — 目标仓文本接受 UTF-16

日期：2026-11-27

## 本版

`gate-evidence`、`close-check`、`status-scan` 读取 progress.yaml、回链和测试报告时，接受 UTF-8 与 UTF-16（含 BOM；UTF-16 LE 的 ASCII 文本无 BOM 也可）。PowerShell `>` / `Out-File` 写出的文件不再被当成乱码。

技能包自身的源文件仍要求 UTF-8、无 BOM、LF。

## 验证

- `node scripts/selfcheck.mjs`
- `node scripts/sync-skill-version.mjs --check`
