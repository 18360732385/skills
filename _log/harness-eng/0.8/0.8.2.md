## 本版

- **report_schema 0.4.1 → 0.4.2**（`report-ui.mjs` / `score-history.mjs`；0.4.x 族内，历史趋势仍可比）
- **首屏总评横幅**（替代原施工阶梯位）：Verdict 徽章（能否开干，红/绿框）+ 大分数（0–100）+ 等级（≥90 优秀 / ≥75 良好 / ≥60 合格 / <60 待改进）+ 一句话结论（headline）+ 分项 chips（文档质量分 / 代码覆盖率 / 验收通过率 / 开干清单%）+「仅参考 · ≠开干」角标；公式沿用原仪表参考分（35/25/20/20，缺项归一化），改名「总评分」，从趋势台移出
- **施工阶梯移入决策台**，与开干清单同组（`.pipe-group`）；10 秒结论区精简为「还差什么 / 建议升阶」（verdict/hint 上移横幅或移除；`one_line_zh` 留数据层）
- **术语人话化**（原词进名词解释 tooltip）：形态分→文档质量分 · 覆盖→代码覆盖率 · 金标达标率→验收通过率 · 语义闸→语义抽检 · 填充计划→补文档计划 · 残差→验收遗留项 · 分片→补文档任务 · 贴公式上限→已达理论上限 · 开干闸路径→开干清单 · 低分真相→低分原因 · 宿主台→落地检查台；GLOSSARY 新增 总评分 / 开干清单 / 落地检查 三词条
- **结构简化**：KPI 灯组并入开干清单（决策台，六步状态即原四灯）；「还差什么」机器码仍可折叠展开；诊断台「常见缺口分布」「低分原因 Top」改 `<details>` 折叠；趋势台仪表参考分块移除；顶栏副标题去 skill_version/report_schema（仍留页脚）
- **降噪（保身份）**：标题去 `CYBERPUNK TERMINAL`；移除 CRT 扫描线 / 网格纹理 / glitch 切换 / 闪烁光标 / 进度条扫描光 / pulse / Orbitron 字体 / 硬编码霓虹 text-shadow；深浅双主题与角标装饰保留
- **视觉精修（工程图纸 × 夜班表盘）**：亮色=草图纸（#edf0e9 + 墨绿 #0e7a4e）、暗色=蓝绿黑（#0e1418 + 荧光绿 #46d18e，摆脱「纯黑+酸性绿」默认脸）；Verdict 徽章改**验收印章**（双环边框 + rotate(-2°) + 字距拉开，全页唯一装饰性元素）；等宽字体只做仪表读数（分数/百分比/命令/状态位），标题回归 IBM Plex Sans SC 700；去按钮 `[]` 括号、`> / ▶ / // / ◆ / »` 前缀与 ALL-CAPS 标签；制图角标收敛到 deck + 横幅；`:focus-visible` 焦点环；line-height 1.6
- **横幅排版与动效（同轮迭代）**：分数改纵排仪表面（标签在上/大读数+等级居中/仅参考注在下）+ 方格坐标纸底纹 + 竖向虚线中缝；「盖章时刻」一次性入场编排——印章 stamp-in 缩压入场 + stamp-ring 冲击环 + 总评分 countUp 滚动（600ms，setTimeout 兜底保证后台标签页终值落定）+ 双进度条 rAF 生长；**阶梯/清单宽屏双列并排**（1fr 1fr + 虚线中缝，<860px 回落纵叠）；光效仅暗色主题（表盘数字磷光 text-shadow + 进度条辉光），亮色纸面不加光；全部动效受 `prefers-reduced-motion` 全局闸门 + `--force-prefers-reduced-motion` 无头验证通过
- **机器字段不动**：`score` 原样；`ai_coding_ready` 判定不变；tech 弹层保留英文标识符；`composite_score` 字段名不变（session-dashboard 兼容）
