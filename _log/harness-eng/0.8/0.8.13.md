# 0.8.13 — 实战报告缺陷收口（audit 抗行尾 / id 唯一 / 预授权 / 安装态自检）

日期：2026-11-27

## 本版

来源：harness-eng 0.8.11 升级 sms-ai 实战总析的「仍存缺点」。逐项判定后只修技能自身缺陷，计分口径与 gold 门槛不动。

- **audit 抗行尾**：`coverage-audit` 的 `truth_sha256` / `evidence_sha256` 改为规范化内容哈希（去 UTF-8 BOM、CRLF/CR 归一 LF；二进制按原字节）。校验同时接受旧原始字节与等价行尾变体，Windows `core.autocrlf=true` 下不再因 checkout 行尾把 audit 判 stale；真实改文仍判 stale
- **原型 id 全局唯一**：`uniquifyAssetIds` 改为全局 `used` 集合并循环补号，预置 `x-2` 不会与补号撞车
- **重复 unit_id 不计两次**：`inventoryUnitIds` 去重；`validateAudit` 防御性去重。重复 id 不再把同一条 audit 重复计 pass
- **预授权可单独取消**：`确认预授权` / `取消预授权` 只需 `--root`，不因缺 `--mode` / `--params` 只打 Usage
- **安装态 selfcheck 全量**：0.6.x–0.7.51 迁移与验收历史随包进 `archive/`，`upgradeCorpus` / `verifyCorpus` 先读随包语料；钉住/安装副本不再 59 条历史断言红
- **refresh 告警与身份**：refresh 也提示安装副本版本/rev 错位，覆盖 `.cursor/.trae/.claude/.codex/.qoder/.codebuddy/.workbuddy`（`HARNESS_INSTALL_ROOTS` 可追加）；成功 refresh 回写 `harness-meta.last_mode: "refresh"`
- **audit 孤儿可见**：`validateAudit` 返回 `orphans` / `orphan_count`；`fill-score` 写入 `coverage_audit.by_domain`，refresh hints 提示人工对账（不自动搬移）

## 不修（设计限值）

- gitignore 追加机制：目标仓删除模板行仍会在下次 render 补回；0.8.12 已移除报告三件套，通用机制按「只追加缺失行」契约保留
- client-api `type_export` 不计分：避免覆盖虚高的既定口径，报告已写明排除数量
- 覆盖=点名、audit 不读正文：文档化的真实性边界
- rule 17 与 101 并存：只告警 + `git mv` 命令，不自动删
