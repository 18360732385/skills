## 本版

- func 身份认出 `ServiceImpl`（以及 Component / Manager / Handler 的 Impl）
- 变更记录只剥离 `##` 级标题，`### 变更记录` 不再把整节正文丢掉
- `acceptance-check` 的 version 跟 `_meta/manifest.yaml`
- 无升严 blocker 时，已有 migrate ops 只刷新时间戳；没有旧计划才写空心跳
- 形态到顶但金标未过时，报告写「未过线」，不再把「已达理论上限」叫拖后腿
- API 路径、类名、Redis 模式按边界判断是否已写入，短前缀不再算已覆盖
- `CREATE TABLE IF NOT EXISTS` 后面没有表名时不再得到表名 `IF`
- Redis 覆盖计数与身份槽同一套 Key 模式解析
- prototype inventory 消解重复 id 并告警
- jobs 真实性记录不在 `tasks/` 时，reason 写明期望前缀
- client-api 索引写明计分排除 `type_export`
- refresh 打分成功后重建 `report-latest.html`（失败只提示）
