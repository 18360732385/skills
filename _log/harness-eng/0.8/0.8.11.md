# 0.8.11 — 确认令牌、rev 新鲜度、预授权落盘、UTF-16 JSON

日期：2026-11-27

## 本版

- 真写 `harness.mjs` / `render.mjs` 需要 `--confirm` 闸门词。`--dry-run`、backfill、只读检查不需要。脚本失败后不要手工 Write
- `--confirm 确认预授权` 只写入 `docs/harness-eng/write-auth.yaml`。之后的写盘可省略 `--confirm`。`取消预授权` 写成 `preauth: false`
- `Q_PREAUTH` 的推荐值改为 false。`全部推荐` 不再把它收成已授权
- 安装副本告警比较 version 和 rev。L5 freshness 比较 `HARNESS_ENG_REV`。`harness-meta` 增加 `skill_rev`
- JSON 与目标仓文本（render 合并、migrate-docs、write-auth）接受 UTF-8 / UTF-16（含 BOM，以及 UTF-16 LE 的 ASCII 文本）
- CI 增加 `windows-latest`

报告壳仍是 0.4.3。
