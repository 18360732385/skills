# 0.7.51 — SQL 迁移命名双轨契约回流

日期：2026-10-29

来源：sms-ai §4.7 v3.54（2026-10-26 定稿）命名体系核查后的定向回流——补齐 0.7.49 只回流「机制壳」的缺口：双轨识别、检查降噪、生成器本体、最高号禁令。

## 要点

- **soft-gate 双轨命名检查**：新增 `MIGRATION_OLD_NAME_RE` 占位（`null`=单轨，默认向后兼容）；`collectMigrationNamingReminders` 升级——新增（A）/改名（R）的新路径都查、存量改内容（M）不刷屏；命中旧格式 → 专属文案「存量可保留、新文件请用新格式」，与「文件名不合规」分离
- **注入链**：`hooks-checks.mjs` `migration_old_name_re`（params / `registry.db.hook_old_name_re` / 占位三通道；JSON.stringify 或 null 下发）；`domains.yaml` db 域加 `hook_old_name_re` 可选键
- **生成器可选包**：`migration-naming-lib`（`migration_naming.py.tmpl`：双轨正则/说明校验/version 主键/双轨排序/跨作者发号避让；`MIGRATION_DIR_REL` / `MIGRATION_TZ` 占位，旧轨正则按仓调整可置 None）+ `new-migration-py`（`new_migration.py.tmpl`：`--type DDL|DML` / `--pair` 同毫秒双轨 CLI + 文件头渲染含 DDL·DML 禁混写提示）；render.mjs 补两占位默认
- **最高号禁令**：13 rule「迁移模式与命名」+ db.md「迁移命名」补「禁止把当前最高号/最新时间戳写死进 AGENTS.md / README.md / docs/db/db.md（目录即清单）」（对应 sms-ai P3/P21/P51 系）
- **questions**：Q_DB_MIGRATION note 升级为三件可选（env_status_cmd / new_script / old_name_re）+ 生成器包提示
