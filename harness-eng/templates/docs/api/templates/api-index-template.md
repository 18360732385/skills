### 字段表约定（模块真相强制）

基线列（新建/大改）：`| 参数名 | 类型 | 必填 | 说明 | 枚举 | 备注 | 示例值 |`（可选 `默认`）。

| 列 | 内容 |
|---|---|
| **说明** | 字段中文含义（短名） |
| **枚举** | 取值全集；无则 `—` |
| **备注** | 条件必填、默认、错误码、特殊逻辑；无则 `—` |
| **必填** | 仅恒必填；条件必填写备注 |
| **示例值** | 具体样例或显式 `未知`/`—`/`N/A`；禁止空单元格 |

请求与**响应**表均须带 **必填**。旧 5 列（枚举写在说明里）仍兼容 acceptance。全文见 [`api-doc-template.md`](./api-doc-template.md)。
