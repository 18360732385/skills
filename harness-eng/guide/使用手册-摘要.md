# harness-eng 一分钟导读

> 版本：**0.7.14**（以 `templates/_meta/manifest.yaml` 为准）

给业务同学 / 负责人的短文。完整版见 [使用手册.md](使用手册.md) · 浏览器版 [使用手册.html](使用手册.html)；Agent 施工入口见 [QUICKSTART.md](../QUICKSTART.md)。

## 它是什么

一套 **AI 编程脚手架施工技能**：按**对外三档**（协作入口 · 契约与回流 · 门禁·工具·SSOT）把骨架装进目标仓；多工具共用 **一份真相**。细阶仍是 L0–L5。

## 解决什么

- 换 AI 工具就丢规则、各写一套互相打架  
- 接口 / 库表 / Redis 只在人脑里，Agent 只能猜  
- 仓库里有很多 markdown，但说不清能不能放心让 AI 改业务  

## 怎么用（对外四支）

1. **一句话安装**：「帮我把这个 skill 装到你当前 Agent 宿主的用户 skills 目录，地址：https://github.com/18360732385/skills/tree/main/harness-eng」。或 `npx skills add <同上URL> -g`。装完**新开会话**再点名 harness-eng。生产用 **`main`**。  
2. 按支说话：大仓首次 → **流水线**；看缺口 → **审计**；半成品 → **续跑**（施工）；深填/打分 → **填充**。  
3. Agent 出 WritePlan 后，回复 **确认**（或预授权）才会写盘。  
4. 不确定选项就回 **全部推荐**，再确认一次。

## 多 AI 工具怎么共仓

- 真相只在 `AGENTS.md` + `docs/**`。  
- 对齐：**Cursor/Claude/Qoder/WorkBuddy 高**；**Trae 高**；**Codex 高 · 纪律 B**（不做 `.mdc` 镜像）。WorkBuddy/CodeBuddy（**0.6.4**）：扁平 rules + `/hooks` + 根 `.mcp.json`（见 [CODEBUDDY-PARITY.md](../host/CODEBUDDY-PARITY.md)）。  
- 长期多工具维护，升到 **L5**（`docs/agent-config` + sync）。

## 怎样才算能 AI Coding

打开目标仓 `docs/harness-eng/report-latest.html`：

| 决策台读数 | 结论 |
|---|---|
| 徽章 **「建议可以开干」** + 可 AI coding **YES** | 可以开干（仍须人工审） |
| 「建议暂缓」/ 开干 NO / 有 blockers | 不可以 |
| 仅 overall / 金标 / 参考分很高 | 不可以（参考分 ≠开干） |

详细五台说明见 [使用手册.html](使用手册.html#s6) / [使用手册.md](使用手册.md) 第 6 章。

## 记住三句话

1. **写盘前确认**（或预授权）。  
2. **开干只看决策台 `ai_coding_ready`**。  
3. **契约一份，工具入口多份**；真密 local 可填、勿提交。
