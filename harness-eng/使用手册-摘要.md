# harness-eng 一分钟导读

> 版本：**0.7.7**（以 `templates/_meta/manifest.yaml` 为准）

给业务同学 / 负责人的短文。完整版见 [使用手册.md](使用手册.md) · 浏览器版 [使用手册.html](使用手册.html)；Agent 施工入口见 [QUICKSTART.md](QUICKSTART.md)。

## 它是什么

一套 **AI 编程脚手架施工技能**：把「协作入口 + 契约文档 + 知识回流 + 软门禁 + MCP 样例」按阶梯装进目标仓库，并支持 Cursor / Claude / Qoder / Trae 等多工具共用 **一份真相**。0.7.0 起（Codex **高**；其上 0.6.8-dev / 0.6.7）强化 **Pn 回流**与前后端契约门禁；0.6.6 起可选 **OpenAPI→Apifox 桥**，分册 AGENTS 为厚 SSOT 骨架。

## 解决什么

- 换 AI 工具就丢规则、各写一套互相打架  
- 接口 / 库表 / Redis 只在人脑里，Agent 只能猜  
- 仓库里有很多 markdown，但说不清能不能放心让 AI 改业务  

## 怎么用（对人说）

1. **一句话安装**：「帮我把这个 skill 装到你当前 Agent 宿主的用户 skills 目录，地址：https://github.com/18360732385/skills/tree/main/harness-eng」。或 `npx skills add <同上URL> -g`（需要时按宿主加 `--agent`）。装完**新开会话**再点名 harness-eng。路径因宿主而异（Cursor：`~/.cursor/skills/` 或 `skills-cursor`；Claude Code：`~/.claude/skills/`；Trae：`~/.trae/skills/` 或项目 `.trae/skills/`——示例≠唯一安装目标；其他按该宿主文档）。生产装/升用 **`main`**。0.6 系列开发在 `V0.6.X`，合并进 `main` 后生产再装/升。  
2. 大仓第一次说「跑**流水线**」；只想看缺口说「**审计**」；半成品说「**续跑**」。  
3. Agent 出 WritePlan 后，回复 **确认**（或预授权）才会写盘。  
4. 不确定选项就回 **全部推荐**，再确认一次。

## 多 AI 工具怎么共仓

- 真相只在 `AGENTS.md` + `docs/**`。  
- 落地时多选工具面，各产品只拿薄入口指针。对齐：**Cursor/Claude/Qoder/WorkBuddy 高**；**Trae 高**；**Codex 高 · 纪律 B**（探测到 `.codex/` 或显式勾选才进「全部推荐」；不做 `.mdc` 镜像）。WorkBuddy/CodeBuddy（**0.6.4**）：扁平 `.codebuddy/rules/*.md` + `/hooks` + 根 `.mcp.json`（[CODEBUDDY-PARITY.md](host/CODEBUDDY-PARITY.md) · [CODEBUDDY-P0-MANUAL.md](host/CODEBUDDY-P0-MANUAL.md)）。  
- 无探测时「全部推荐」不默认 Cursor；只生成 AGENTS 级指针，不因此只写 `.cursor/` 适配。  
- 长期多工具维护，升到 **L5**（`docs/agent-config` 一处改、再 sync）。L3+ / L5 全量镜像宿主不再强制冗余 `1x-contract-sync`。Codex + L5：`sync.mjs` 发原生 rules/hooks/MCP/skills（**高 · 纪律 B**；不做 `.mdc` 镜像）。

## 怎样才算能 AI Coding

打开目标仓 `docs/harness-eng/report-latest.html`（施工仪表盘）：

| 决策台读数 | 结论 |
|---|---|
| 徽章 **「建议可以开干」** + 可 AI coding **YES** | 可以开干（仍须人工审） |
| 「建议暂缓」/ 开干 NO / 有 blockers | 不可以 |
| 仅 overall / 金标 / 参考分很高 | 不可以（参考分 ≠开干） |

施工/审计等**本轮实质产出或闸门决策/显式读数**另有**会话仪表盘**（四台摘要 + 可选纯文本态势 +「详情请查询仪表盘」链）；提问批次 / 定根前 / 等确认空轮 / 纯问版本 / 手册 / 跑题则省略。  
详细四台说明见 [使用手册.html](使用手册.html#s6) / [使用手册.md](使用手册.md) 第 6 章（会话仪表盘）。

## 记住三句话

1. **写盘前确认**（或预授权）。  
2. **开干只看决策台 `ai_coding_ready`**。  
3. **契约一份，工具入口多份**；example 无密可入库；真密 local 可填、默认不随技能分发。
