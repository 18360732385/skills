# harness-eng 一分钟导读

给业务同学 / 负责人的短文。完整版见 [使用手册.html](使用手册.html) / [使用手册.md](使用手册.md)；Agent 施工入口见 [QUICKSTART.md](QUICKSTART.md)。

## 它是什么

一套 **AI 编程脚手架施工技能**：把「协作入口 + 契约文档 + 知识回流 + 软门禁 + MCP 样例」按阶梯装进目标仓库，并支持 Cursor / Claude / Qoder / Trae 等多工具共用 **一份真相**。

## 解决什么

- 换 AI 工具就丢规则、各写一套互相打架  
- 接口 / 库表 / Redis 只在人脑里，Agent 只能猜  
- 仓库里有很多 markdown，但说不清能不能放心让 AI 改业务  

## 怎么用（对人说）

1. **一句话安装**：「帮我安装这个 skill，地址：https://github.com/18360732385/skills/tree/main/harness-eng，装到 ~/.cursor/skills/harness-eng」。或 `npx skills add <同上URL> -g --agent cursor`。装完**新开会话**再点名 harness-eng。  
2. 大仓第一次说「跑**流水线**」；只想看缺口说「**审计**」；半成品说「**续跑**」。  
3. Agent 出 WritePlan 后，回复 **确认**（或预授权）才会写盘。  
4. 不确定选项就回 **全部推荐**，再确认一次。

## 多 AI 工具怎么共仓

- 真相只在 `AGENTS.md` + `docs/**`。  
- 落地时多选工具面，各产品只拿薄入口指针。  
- 长期多工具维护，升到 **L5**（`docs/agent-config` 一处改、再 sync）。

## 怎样才算能 AI Coding

打开目标仓 `docs/harness-eng/report-latest.html`（施工仪表盘）：

| 决策台读数 | 结论 |
|---|---|
| 徽章 **「建议可以开干」** + 可 AI coding **YES** | 可以开干（仍须人工审） |
| 「建议暂缓」/ 开干 NO / 有 blockers | 不可以 |
| 仅 overall / 金标 / 参考分很高 | 不可以（参考分 ≠开干） |

施工/审计等工程轮另有**会话仪表盘**（四台摘要 +「详情请查询仪表盘」链）；纯问版本或手册则省略。  
详细四台说明见 [使用手册.html](使用手册.html) 首页示意与第 6 章。

## 记住三句话

1. **写盘前确认**（或预授权）。  
2. **开干只看决策台 `ai_coding_ready`**。  
3. **契约一份，工具入口多份**；真密不进 example、不随技能分发。
